🖥️ Screen 1 : 메인 페이지
3-1. 초안 프롬프트
초안 이미지 프롬프트
모바일 여행 앱 UI 디자인, 여행 플랫폼 앱 **"Travel Mate"**의 메인 홈 화면.

[전체 무드]
깔끔하고 신뢰감 있는 여행 서비스 디자인. 밝은 화이트 배경을 기본으로 하고 네이비와 블루를 메인 컬러로 사용하며, 검색 버튼과 주요 CTA에는 밝은 코랄 레드 컬러를 포인트로 사용한다. 전체적으로 현대적이고 친근한 모바일 여행 앱 UI, 충분한 여백과 둥근 모서리의 카드형 UI를 적용한다.

[상단 영역]
상단 좌측에 "Travel Mate" 브랜드 로고를 배치하고, 로고 옆에 작은 비행기 아이콘을 사용한다. 우측에는 알림 아이콘과 찜하기 하트 아이콘을 둥근 흰색 버튼 형태로 배치한다.

[메인 헤더]
"여행을 시작해요 👋"라는 큰 제목을 배치하고, 아래에 "새로운 여행이 당신을 기다리고 있어요."라는 설명 문구를 배치한다. 오른쪽 또는 배경 영역에는 산토리니의 푸른 지붕과 바다를 연상시키는 밝고 청량한 여행 이미지를 배치한다.

[검색 영역]
큰 둥근 검색창을 배치하고 검색 아이콘과 함께 "어디로 갈까요?" 문구를 표시한다.

검색창 아래에는 세 가지 입력 영역을 배치한다.

날짜 선택
여행 인원 2명
검색 버튼
검색 버튼은 코랄 레드 컬러의 둥근 버튼으로 구성한다.

[추천 여행지]
"추천 여행지" 제목과 "전체보기" 링크를 배치한다. 아래에는 가로 스크롤 가능한 여행지 카드 리스트를 구성한다.

여행지 예시:

파리
발리
도쿄
후지산 지역
각 카드에는 여행지 대표 사진, 위치 아이콘, 여행지 이름과 간단한 소개 문구, 하트 아이콘을 배치한다.

[하단 영역]
"내 여행을 한눈에 관리해 보세요"라는 파란색 안내 배너를 배치하고, 예약 확인 및 일정 관리 기능을 안내한다.

하단 고정 네비게이션에는 다음 메뉴를 배치한다.

홈
검색
여행
프로필
현재 선택된 홈 메뉴는 블루 컬러로 강조한다.

[스타일 디테일]
화이트 기반, 네이비·블루·코랄 컬러 조합, 둥근 카드와 버튼, 부드러운 그림자, 여행 사진을 활용한 현대적인 모바일 UI. 전체 화면은 실제 앱 화면처럼 보이는 세로형 모바일 스크린으로 구성한다.

초안 결과 이미지
초안 문제점 분석
텍스트 및 정보 표현 문제:
AI 이미지 생성 특성상 작은 UI 텍스트가 일부 부정확하게 표현될 가능성이 있었으며, 실제 앱에서 사용되는 버튼과 메뉴의 정보 위계를 명확하게 표현할 필요가 있었다.

레이아웃 문제:
여행 추천 카드와 검색 영역이 동시에 배치되기 때문에 화면 상단에 정보가 과도하게 몰리지 않도록 검색 영역과 추천 콘텐츠 사이에 충분한 여백이 필요했다.

브랜딩 문제:
여행 앱이라는 특성은 표현되었지만 단순한 여행 서비스가 아닌 Travel Mate만의 브랜드 아이덴티티가 드러날 수 있도록 로고와 네이비·블루 컬러 시스템을 명확하게 적용할 필요가 있었다.

기타:
하단 네비게이션의 선택 상태가 명확하게 구분되어야 하며, 추천 여행지 카드는 사용자가 여행지를 직관적으로 인식할 수 있도록 사진 중심으로 구성할 필요가 있었다.

3-2. 수정 프롬프트
수정 이미지 프롬프트
기존 Travel Mate 모바일 여행 앱 홈 화면의 전체적인 레이아웃과 디자인 스타일은 유지한다.

상단에는 Travel Mate 로고를 명확하게 표시하고, 네이비와 블루 컬러를 사용하여 브랜드 아이덴티티를 강화한다.

검색창은 화면에서 가장 중요한 입력 영역으로 보이도록 넓고 둥근 형태로 유지하며, 검색 아이콘과 "어디로 갈까요?" 문구가 명확하게 보이도록 한다.

검색창 아래에는 날짜 선택, 여행 인원, 검색 버튼을 가로로 정렬한다.

추천 여행지 영역에는 실제 여행지 사진을 활용한 카드형 UI를 배치한다.

추천 여행지는 다음과 같이 구성한다.

파리 / 발리 / 도쿄 / 후지산

각 카드에는 위치 아이콘과 여행지 이름을 명확하게 표시하고 하단에는 간단한 여행 소개 문구를 배치한다.

하단에는 "내 여행을 한눈에 관리해 보세요" 안내 배너를 배치하고, 최하단에는 홈 / 검색 / 여행 / 프로필 네비게이션을 유지한다.

전체적으로 화이트 배경 + 네이비 + 블루 + 코랄 포인트 컬러, 둥근 모서리, 넉넉한 여백, 사진 중심의 여행 카드 디자인을 유지한다.

스마트폰 기기 자체가 아닌 순수 모바일 UI 화면으로 표현한다.

수정 이유
메인 화면은 사용자가 앱에 진입했을 때 가장 먼저 여행지를 탐색하고 검색하는 화면이기 때문에 검색 기능과 추천 여행지의 시각적 우선순위를 높이는 방향으로 수정하였다.

또한 Travel Mate라는 서비스명이 화면에서 명확하게 인식되도록 브랜드 로고를 강조하고, 전체 화면에서 동일한 네이비·블루·코랄 컬러 시스템을 적용하여 브랜드 일관성을 확보하였다.

수정 결과 이미지
수정 후 달라진 점
변경 전:
여행 앱의 기본적인 검색 및 추천 구조 중심

Travel Mate 브랜드 로고 강조

하단 네비게이션을 통한 주요 기능 접근성 강화

3-3. 최종 프롬프트
최종 선택 이유
수정본은 여행 서비스에서 가장 중요한 검색 기능과 추천 여행지 콘텐츠를 한 화면에서 직관적으로 확인할 수 있다는 점에서 최종안으로 선택하였다.

특히 Travel Mate 로고와 네이비·블루 컬러를 중심으로 브랜드 이미지를 명확하게 구성했으며, 코랄 컬러의 검색 버튼을 사용하여 사용자가 다음 행동을 쉽게 인식할 수 있도록 하였다.

또한 추천 여행지 카드와 하단 네비게이션을 함께 배치하여 여행 탐색부터 다른 기능으로의 이동까지 자연스럽게 연결되도록 구성하였다.
